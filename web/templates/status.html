Security

  • The GitHub Personal Access Token is read from the GITHUB_TOKEN environment variable, held in memory only, and never written to PostgreSQL, logs, HTML or API responses.
  • Only {{.Org}} is queried. Other organizations the token can reach are never enumerated or imported.
  • DevPulse needs read-only GitHub permissions; it never writes to GitHub.
